### 2. FF 索引→VRAM code 映射规则确认
- **FF idx ≥ 0x80 → 直接映射** (VRAM code = idx)
  - FF 0x83→0x83=明 ✓, FF 0x92→0x92=日 ✓
- **FF idx < 0x80 → 偏移映射** (VRAM code = idx + 0x3A)
  - FF 0x58→0x92=日 ✓, FF 0x47→0x81=意 ✓, FF 0x36→0x70=ボ
  - FF 0x17→0x51=ウ ✓, FF 0x03→0x3D=み ✓

## 编码规则总结
```
0x00-0x7F: 假名/符号（kana_table，种子验证 15 处修正）
0x80-0xEF: 汉字（kanji_table，直接 VRAM code）
F0-F5: 控制码（F3=行首, F1=翻页）
F6: 换行
FF xx: 双字节汉字
  - xx >= 0x80: VRAM code = xx（直接）
  - xx < 0x80: VRAM code = xx + 0x3A（偏移）
```
